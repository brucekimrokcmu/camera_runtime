| Stage              | OpenCV API                                    |
| ------------------ | --------------------------------------------- |

| Threshold          | `cv::inRange`                                 |

| Area               | `cv::contourArea`                             |
| Bounding box       | `cv::boundingRect`                            |

| Drawing            | `cv::rectangle`, `cv::circle`, `cv::putText`  |
| Resize             | `cv::resize`                                  |
| Camera calibration | `cv::calibrateCamera`                         |
| Chessboard         | `cv::findChessboardCorners`                   |
| Undistortion       | `cv::undistort`, `cv::remap`                  |
| Perspective        | `cv::solvePnP`                                |
